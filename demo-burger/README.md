# Smash House — موقع تجاري (طنجة)

موقع مطعم برغر تجاري كامل: قائمة ثابتة، طلب عبر واتساب مع سلة ونوافذ،
ومشهد افتتاحي ثلاثي الأبعاد تحريري (تجربة بصرية) لا يعيق الطلب أبداً.

## البنية

```
demo-burger.html            الصفحة (HTML ثابت وكامل — يخدم بلا JavaScript)
demo-burger/
├── css/main.css            كل الأنماط (متغيرات / أساس / مكونات / أقسام / تجاوب)
├── js/
│   ├── config.js           ★ إعدادات المطعم — عدّل من هنا فقط
│   ├── app.js              تنقل، فلاتر، ظهور، عدادات
│   ├── order.js            السلة + نوافذ الطلب + رسالة واتساب
│   └── scene.js            محرك المشهد 3D (تهيئة كسولة + وضع ثابت عند اللزوم)
├── data/menu.json          القائمة بكل الحقول (مرجع/مزامنة مع HTML)
├── gl/                     ⚠️ مكتبات وصور مشتركة مع 15 صفحة أخرى — لا تلمسها
├── img/                    صور المطعم — لا تنقلها (صفحات أخرى تعتمد عليها)
└── favicon.svg
```

## كيفاش تعدّل

- **الاسم، رقم واتساب، التوصيل، العنوان، الساعات، السوشيال** → `js/config.js` فقط.
  القيم `null` = معلومة ناقصة: قسمها يختفي من الموقع حتى تعمّرها.
  ملاحظة: روابط واتساب الافتراضية في HTML (للزوار بلا JavaScript) تحمل نفس
  الرقم — بدّله فيها أيضاً إذا تغيّر.
- **القائمة والأثمنة** → عدّل بطاقات HTML في قسم `#menu` داخل `demo-burger.html`
  وزامن `data/menu.json`. أزرار الطلب تحمل `data-id/name/price/extras` —
  نظام الطلب يقرأ منها، فلا تحذفها.
- **ألوان الهوية** → متغيرات CSS في أول `css/main.css` (`--acc` أحمر، `--acc2` وردي).

## التشغيل محلياً

```bash
cd ~/workspace/mounir-web
python3 -m http.server 8901
# http://127.0.0.1:8901/demo-burger.html
```

الموقع ثابت بالكامل (بلا build). النشر يتم مركزياً عبر GitHub Pages.

## سلوك المشهد 3D

- يبدأ كسولاً بعد تحميل الصفحة؛ إذا فشل WebGL أو تأخر أكثر من ثانيتين
  أو فضّل الزائر تقليل الحركة أو كان الجهاز ضعيفاً → **وضع ثابت**:
  صورة رئيسية + نص تجاري، والصفحة كاملة الوظائف.
- زر «تخطي الحركة» في الهيرو يحوّل للوضع الثابت ويهبط للقائمة.
